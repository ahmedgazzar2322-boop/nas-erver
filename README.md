# THOTH // 24/7 Multi-Drive NAS Cloud & Stocks Analytics Explorer

A dedicated 24/7 Multi-Drive NAS Cloud Storage & Stock Analytics web dashboard for **THOTH_AI** running on Raspberry Pi.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/ahmedgazzar2322-boop/nas-erver.git)

---

## ⚡ Features
* **Multi-Drive USB Explorer**: Browse the 128GB NAS Cloud storage and the 8 protected system partitions on your Raspberry Pi.
* **Stocks Analytics Vault**: Instant access and PDF/Excel downloads for `/Daily/`, `/Monthly/`, `/Yearly/`, and `/All-Time/` reports.
* **Full Read/Write on 128GB NAS Drive**: Drag-and-drop file upload, folder creation, instant search, and downloads.
* **Strict Read-Only Protection on System Partitions**: Prevents accidental deletion of databases, models, and auth vaults.
